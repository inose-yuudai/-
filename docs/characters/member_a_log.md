## 経過

### 2026-10-12

- 依頼: 写真の人物を、ゲームの画風に合わせた 3D キャラにする（立ち絵 → 3D → リグとモーション → Unity 用の FBX）。
- **Tripo を操作できず、生成は 0 回。** 理由は 2 つ。
  1. この作業はクラウドの環境で動いていて、依頼者の Chrome（Tripo にログイン済み）を操作する拡張機能（Claude in Chrome）につながっていない。
  2. この環境のネットワーク設定で、`api.tripo3d.ai` `studio.tripo3d.ai` `www.tripo3d.ai` への接続が拒否された。
- 等身の解釈: 依頼文の「1 枚目の主人公くらいの等身（5〜6 頭身）」について、今回の添付の 1 枚目（剣と盾のキャラ）は約 2.5 頭身だった。数字の指定を優先し、5〜6 頭身の主人公「あなた」（今回の添付の 2 枚目）に合わせると判断した。
- 立ち絵のポーズを、A ポーズから依頼どおりの T ポーズに変更した。プロンプトの全文は [`tools/tripo/characters/member_a.json`](../../tools/tripo/characters/member_a.json) の `concept.prompt` にある。
- モーションを依頼の 7 つに合わせた（使わない `turn` を外した）。

### 2026-10-13

- 依頼: Claude in Chrome で Tripo を操作し、手順 1 の立ち絵を作る（プロンプトは `concept.prompt`、`{proportion}` は `proportion_prompts.hero`、画像は添付の順番どおり）。
- **今回も生成は 0 回。** 前日と同じ 2 つの理由で、Tripo を操作できなかった。
  1. この作業環境に Claude in Chrome のツールがない（拡張機能につながっていない）。
  2. `studio.tripo3d.ai` `www.tripo3d.ai` `api.tripo3d.ai` への接続が、環境のネットワーク設定で拒否された（プロキシが 403 を返した）。
- 添付の順番は「1 枚目 = 剣と盾のちびキャラ、2 枚目 = 主人公『あなた』、3〜5 枚目 = 人物の写真」だった。プロンプトは「1 枚目 = 主人公、2 枚目 = ちびキャラ」を前提にしているので、**添付の順番のままアップロードすると等身の指示が逆になる。** 実行の前に、どちらに合わせるかを決める必要がある。
